# 蛋仔形象与衣柜实施计划

**目标：** 经典黄蛋仔外形、六套皮肤、岛上实时试穿与本地保存。

**实现：** Blender 可编辑模型保留 Body / ArmL / ArmR / FootL / FootR 动画节点，语义材质支持换色；独立皮肤目录、存储对象和衣柜预览窗口。碰撞体和移动参数保持当前数值。

**技术：** Godot 4.7.2、GDScript、Blender Python。
