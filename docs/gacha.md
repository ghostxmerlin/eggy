# 本地盲盒与机甲主题池

2026-09-13。用户选定早期的断罪骑士银白机甲。当前是参考其外观自建的模型与本地主题奖池，不是正式服模型、原始赛季奖池或抽卡接口。

2026-09-14：按用户要求，至臻“断罪骑士·极”改为黄金装甲、深金边缘、浅金高光与金色能量眼；岚、烈保留各自配色。皮肤 ID 仍为 `mecha`，已有收藏和穿着自动使用新配色。

岛上按 **G** / 点击“盲盒”进入工坊；按 **回车** 打开输入框，输入 `+500` 再回车，增加 500 蛋币。支持其他正整数、数字小键盘 Enter；Esc 取消。不足时不会进行部分抽取。工坊也支持回车加币；衣柜、结果与说明弹窗的 Enter 仍操作焦点按钮，空格也可操作按钮。岛上参赛改为点击“参赛”；比赛结算 Enter 仍重试。

## 奖池

| 奖池 | 品质基础概率 | 单抽 / 十连蛋币 |
|---|---|---|
| 常驻 | 基础 70%、高级 20%、稀有 10% | 10 / 90 |
| 机甲主题 | 高级 63.99%、稀有 23.89%、典藏 10.49%、至臻 1.63% | 60 / 540 |

- 常驻：暖绒围巾（基础）、汽水潜水员（高级）、云端飞行员（稀有）。
- 机甲主题：工坊学徒、巡检员（高级）；履带探险家（稀有）；断罪骑士·岚、烈（典藏）；断罪骑士·极（至臻）。同品质内等概率，因此初始高级每套 31.995%、典藏每套 5.245%。
- 赛季至多 50 抽必得典藏或至臻，提前获得会清零计数。初次集齐前高阶奖励不重复：若随机抽中了已拥有高阶，则在剩余高阶中等概率选一套。因此至多三轮、150 抽集齐三套机甲；自然出货也算一轮。集齐后仍有 50 抽高阶保底。两个奖池的计数相互独立，常驻不消耗或重置赛季计数。
- 50 抽强制保底时，高阶初选权重为典藏 1049、至臻 163，再应用不重复保护。以上品质数字为基础概率，计入这些保护后的实际高阶占比会提高，并非保证每百抽按固定数量分配。
- 重复返币（本地设定）：常驻基础 / 高级 / 稀有返 2 / 3 / 5；赛季高级 / 稀有 / 典藏 / 至臻返 5 / 10 / 30 / 60。先检查并扣除完整单抽或十连价格，再返币。
- 本地池精简为套装，不含表情、饰品、隐藏款、限时折扣或真实充值。三款机甲有不同头角、肩甲、侧翼结构；装甲手脚沿用角色动画节点，所有外观共用原有碰撞体与运动参数。

## 保存与测试

开盒演出顺序为蓄能、上下壳分离、最高品质奖励登场、完整结果展示。粒子、动态光环和卡片流光按品质变色，至臻使用金色；配有原创蓄能、开壳与登场音效。单抽显示大卡片，十连按抽取顺序逐张展开。点击“跳过动画”或 Esc 跳到同一批结果，不重抽、不重复扣币；结果页点击卡片可返回工坊查看该外观。

机甲以连续内壳支撑封闭倒角装甲，背部安装架连接推进器与翼片，四肢连接随实际动画更新。普通套装增加背带、背包安装块与连续呼吸管。预览使用程序生成的摄影棚反射；关闭预览网格自动降级，避免缩略图中贴合的面部穿过外壳。固定配件按材质合并，非均匀缩放使用逆转置矩阵处理法线。

`user://appearance.cfg` 同时保存穿着、蛋币、已拥有套装、赛季计数、累计抽数与最近 50 条结果。旧六套外观继续免费拥有，旧的只含皮肤选择的存档会自动补齐默认字段。提交交易时先写临时文件再重命名，成功后才更新内存；失败不扣币、不解锁，并恢复抽取随机状态。余额上限 999999999，指令只接受正整数；十连是完整的一次保存。

`scripts/gacha_rules.gd` 定义规则；`skin_store.gd` 管存档和原子交易；`gacha_room.gd` 管界面与结果，`gacha_effects.gd` 管演出；`coin_console.gd` 管输入；`outfit_models.gd`、`knight_model.gd` 生成套装几何，`outfit_rig.gd` 连接动画关节。机甲模型隐藏原基础网格的渲染层，恢复基础外观时移除装甲并还原显示；不会改动碰撞层。

```sh
.tools/Godot.app/Contents/MacOS/Godot --headless --path . --fixed-fps 60 --quit-after 3000 --script tests/test_gacha_ui.gd

```

测试使用独立 `test-*.cfg`，不增加玩家余额、不解锁玩家物品。无界面 UI 测试的鼠标路径使用动作调用，真实点击由原生 `--visual` 运行验证。源代码构建与原生窗口已验证；发行包、其他平台及用户对还原效果的认可仍需单独确认。
