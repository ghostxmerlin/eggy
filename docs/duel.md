# 蛋仔决斗场

2026-09-15 更新为固定职业体系：职业在本地角色首次创建时选定，进房间不再换职业。玩家对一名人机，双方各 100 生命，五个技能全部由职业决定。猎人 2 号为猛禽一击，没有宠物；完整技能与天赋见 [职业说明](classes.md)。

## 流程与规则

- 岛上 J / 决斗场 → 首次未选职业时创建 → 展示当前五技能 → 开始（按钮或 Enter）。
- 独立 24×24 场地，边界阻挡角色。3 秒倒计时后双方激活，无时间判胜。
- 真实武器或弹体命中时扣血；技能各有伤害和冷却。一次挥击对同一目标只结算一次。
- 生命归零立即结束，停止双方操作与未完成攻击，显示胜负、耗时、再战、查看技能、返回岛屿。
- Esc 暂停支持倒计时和战斗阶段。T 不复位、不回血；不生成竞速道具。
- 人机按近战/远程职业保持距离，使用真实移动、施法与碰撞，不能透视远处潜行角色；不直接修改玩家生命。
- 职业和天赋沿用角色存档，天赋在岛上 C 修改；不涉及联机、奖励、积分或匹配。

## 回归

`tests/test_duel.gd` 检查职业创建入口、固定职业约束、真实键盘猛禽一击、暂停、胜负、再战、天赋保存与职业参赛。加 `-- --visual` 用鼠标事件操作按钮并截图。`tests/test_classes.gd` 逐招检查二十个技能、控制、反射、免疫、遮挡、位移和四职业人机实战。

```sh
.tools/Godot.app/Contents/MacOS/Godot --headless --path . --fixed-fps 60 --quit-after 32000 --script tests/test_classes.gd
.tools/Godot.app/Contents/MacOS/Godot --path . --always-on-top --max-fps 60 --quit-after 5000 --script tests/test_duel.gd -- --visual
```

测试使用独立存档，不修改用户的职业、蛋币或收藏。首次决斗原来保留的通用 3—5 技能已由本次职业体系替代。
