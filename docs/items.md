# 巅峰赛道具

岛屿参赛进入 1 名玩家 + 31 名人机的道具竞速赛。赛道十排安全平台上分布 44 个问号箱，碰触后随机获得一个道具，箱子四秒后重新出现。一次只能携带一个；满槽不会覆盖已持有的道具。十二种道具使用打乱后的抽取袋，避免某些种类长期抽不到。

**R 使用道具，T 返回检查点／岛屿广场。** W/S、Q/E、A/D、跳跃与 1–5 技能不变。玩家向镜头朝向投掷，右键拖动调整方向。放置类需要前方有可站立的地面，放置失败不会消耗道具。

| 道具 | 本项目中的效果 |
| --- | --- |
| 传送球 | 抛出后命中可站立地面，在施放者当前地面位置与落点生成单向门，持续八秒。经过入口的选手传到出口；撞墙、虚空或被实体占据的落点不会生成门。 |
| 墨汁炸弹 | 抛物线投掷，落点附近对手染上墨汁三点五秒，视野局部遮挡、移动减慢；原有皮肤不被永久改色。 |
| 弹球 | 发射大球，连续碰撞检测，撞飞接触的对手；撞地面或墙体反弹，五秒后消失。 |
| 弹板 | 向面朝方向放置弹板，踩中者向前上方弹出，施放者也能利用；同一选手两秒内不重复触发，十秒后消失。 |
| 炸弹 | 投掷后碰撞爆炸，对附近对手施加向外和向上的真实物理冲量；实体墙体阻挡爆炸影响。 |
| 地雷 | 放置后零点七秒布防，其他选手踩中后一次性爆炸；无人触发时十秒消失。 |
| 云雾弹 | 落点产生五秒烟雾。区域内所有选手视野受遮挡、移动略减慢；走出后恢复。 |
| 加速 | 四秒内将跑步及滚动速度乘以 1.45。 |
| 垫脚箱 | 放置可碰撞、可站立的箱子，十秒后消失。 |
| 弹簧绳 | 抛出钩绳，命中实体后向锚点牵引施放者；命中选手时将双方拉近，位移仍受正常碰撞限制。 |
| 喷气背包 | 启动约两秒的向上推力，可继续控制水平方向，效果到期后正常下落。 |
| 冷却秒表 | 立即恢复现有 1–5 技能的冷却，不取消当前正在进行的动作。 |

人机遵循相同的拾取、占槽与消耗规则，持有道具后短暂等待，攻击类会选择附近对手瞄准，辅助类按赛道前进方向使用。随机种类、物理碰撞和道具干扰会使每场比赛的名次与用时变化。

暂停冻结拾取刷新、弹道、陷阱和状态时间；倒计时、冻结、恐惧、已晋级或乘机状态不能使用道具。掉落复位会清除携带道具与状态，重开／回岛清理场景道具，比赛结束后清理剩余道具。已有的角色质量、皮肤碰撞体、检查点和前 24 名晋级规则继续生效。

玩法名称参考 [Eggy Party 道具列表](https://eggy-party.fandom.com/wiki/Category:Items) 及 [道具说明](https://moegirl.uk/蛋仔派对/强化和道具)。这是使用本项目自制模型、特效与数值实现的十二种道具，并非官方资源或全部版本道具的完整复刻。

实现：`item_catalog.gd`（名称和描述）、`item_state.gd`（每名选手状态）、`item_visuals.gd`（模型）、`race_items.gd`（拾取、投掷、部署与 AI）；`test_items.gd` 检查实际物理效果与生命周期，`test_race.gd` 验证含道具的完整 32 人比赛。
