# 固定职业、技能与反馈

2026-09-15 首版。用户确定职业跟随角色，岛上与决斗共用五技能（巅峰赛后来改为轻松竞速），天赋只调整原技能；猎人取消宠物，2 号猛禽一击，5 号瞄准射击。

## 角色与存档

C 打开职业与天赋。当前本地角色首次创建职业后不可在房间换职业；只有天赋可在对局外调整。存档路径是 `skin_save_path + '.career'`（正常为 `user://appearance.cfg.career`），原子写入，不修改外观/钱包文件。未创建职业时可在岛上继续旧技能练习，决斗的 UI 会先引导创建，巅峰赛可直接进入。当前没有在线账号服务或多角色管理界面。

## 天赋

每职业三行、每行二选一，名称随职业变化，首版数值取舍如下：

1. 伤害提高 15%，或者 1、2 号冷却缩短 18%。
2. 控制持续时间提高 25%，或者受到控制时间缩短 25%。
3. 4 号移动距离提高 20%，或者 4 号冷却缩短 20%。

三行初始均选择左项。没有额外按键，不替换职业的五个技能。天赋在岛上与决斗生效。当前未加入等级、天赋点获取和多层专精树。

## 模式边界

决斗命中扣生命；巅峰赛及单人赛道统一使用滚动、飞扑，不启用职业技能、天赋战斗效果或随机道具。职业 ID 和天赋保留在存档，回岛和决斗时恢复。参赛时会清理施法、状态与弹体。

闪现/暗影步检查实体墙和安全落点；逃脱与冲锋进行物理移动。硬控触发后有覆盖持续时间并额外延长 1.4 秒的控制保护。决斗人机按职业保持近战或远程距离，猎人蓄力时停步。

暂停冻结施法、弹体、状态、粒子更新与技能冷却；结算和重开清除未完成技能、状态、陷阱和弹体。普通岛屿目标也能承受职业技能，岛上显示命中而非生命伤害。

## 视觉、声音及参考

战士使用暖金刀光、金属冲击、反射盾面和怒吼声波；法师使用冰晶、手部法阵、弹体细粒拖尾、脚部定身晶簇和包裹全身的冰封；刺客使用暗影斩击、半透明潜行、眩晕旋转星；猎人使用弓、箭矢、弦声、陷阱冰封和近战反击。每种状态同时有头顶中文倒计时，决斗血条下也显示状态；伤害、抵抗和免疫使用飘字。

`class_effects.gd` 和武器模型均为程序生成，`art/build_class_audio.py` 生成 20 个施放音效及 8 个状态/命中音效。音效按金属、冰晶、暗影、弓弦等音色分层合成，并复用现有附近人机空间混音与防重叠机制。美术、声音属于本项目的改编反馈。

参考：[暴雪职业介绍](https://worldofwarcraft.blizzard.com/zh-cn/game/classes)、[猎人和潜行者天赋预览](https://worldofwarcraft.blizzard.com/en-gb/news/23818247)、[暗影国度技能更新资料](https://worldofwarcraft.blizzard.com/en-us/news/23529209)。这些资料用于选取职业代表技能，并非当前正式服的数值或完整专精复刻。

## 验证入口

- `test_classes.gd`：二十技能实际命中、控制、反射、冰箱、潜行、连击点、遮挡、位移、施法中断、暂停、职业/天赋持久化、四职业人机实战；原生 `-- --visual` 另检查 28 个音效的实际混音输出及截图。
- `test_duel.gd`：新建职业、天赋、决斗/竞速入口；原生验证真实鼠标与数字键操作。
- `test_race.gd`：无需职业，通过 UI 开始完整 32 人轻松竞速，验证冲刺期限及晋级。
- `test_island.gd` / `test_items.gd` / `test_race_ai.gd`：使用底层参赛接口保留旧场景专项，职业选择 UI 另由上面用例覆盖。

职业相互克制与真人操作平衡仍需后续试玩；自动击败静止玩家仅证明人机会使用有效技能。

- `test_light_race.gd`：已有职业/未建职业的竞速入口、实际滚动飞扑按键、屏蔽战斗与道具、首位冲线倒计时、暂停/重开/结算、回岛和决斗恢复职业；`-- --visual` 查看原生截图。
